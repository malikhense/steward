# Review and learning

Close the loop against real results: Do → Review → Learn → Update. Ask whether the habit advanced its goal and whether the goal still expresses the user's values. Review adherence, outcome, burden and fit using available measurements plus the user's experience. A missed routine may reflect timing, ability, pain, unclear instructions, money, enjoyment or competing commitments. Change the system before demanding more discipline.

Use the smallest useful tracking method. If a Plan depends on a measurement, operationalize collection, equipment, routine placement and review; a metric listed in prose is not a feedback loop. Agree a meaningful cadence and decision rule.

When a review identifies an uncertainty that needs a prospective test, use [experiments](../../steward-experiments/SKILL.md) to design or interpret it. Keep ordinary progress reviews grounded in the observations already available.

When follow-up would remove remembering burden, prepare a useful scheduled check-in with its cadence, scope and stop condition. Create it only when requested/authorized and supported. In prototype it remains proposed. A saved skill itself neither runs continuously nor observes the user's life between invocations. Do not promise future monitoring without a verified scheduler.
