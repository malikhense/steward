# Choose a focus

Read [working context](../steward-memory/references/working-context.md) first. This skill owns choosing where attention should go; it can work across health, work, money, home, relationships, learning, recreation, or any area the user names.

1. Recover existing commitments and what prompted the question. Inspect only relevant context; use [context acquisition](../steward-memory/references/context.md) when preferences or constraints are unclear. Establish what currently matters, what is being neglected, and what capacity is actually available. Completion: known commitments and decision-changing unknowns are visible without a whole-life questionnaire.
2. Separate values, desired outcomes, obligations, and candidate strategies. For conflicting goals, climb to their parent purposes before ranking them. Include maintenance, enjoyment, recovery, and choosing not to add a goal. Completion: the choice concerns outcomes the user values rather than whichever proxy is easiest to measure.
3. Compare the few plausible focuses against urgency, expected benefit, dependencies, effort, shared resources, and what would have to be deferred. Use [decision work](../steward-decide/SKILL.md) for a consequential unresolved tradeoff. Offer concrete options when the user has trouble inventing preferences. Completion: recommend a focus with its tradeoff; leave subjective priority to the user when needed.
4. Record a confirmed focus and deferred candidates through [memory](../steward-memory/SKILL.md), keeping suggestions distinct from commitments. If the request includes getting started, continue into [goals](../steward-goals/SKILL.md) or [planning](../steward-plan/SKILL.md) in this task. Completion: the user has either an actionable direction or the smallest meaningful choice needed to select one.

A new area is a record in shared context, not a new skill. Changing focus does not silently pause every existing goal or cancel its live actions.
