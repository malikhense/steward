# Make a plan

Read [working context](../steward-memory/references/working-context.md), then [planning and deliverable criteria](references/planning-deliverables.md). This skill owns feasibility and coherence across the work needed for the outcome.

1. Retrieve the goal, actual baseline, available resources, and existing plan. Discover relevant context using [context acquisition](../steward-memory/references/context.md). Recap material assumptions; distinguish present capacity from the target. Completion: the plan can start from current reality, and missing facts block only their dependent branches.
2. Resolve the approach with [research quality](../steward-decide/references/research-quality.md). For a major unresolved choice use [decisions](../steward-decide/SKILL.md). Build the transition, dependencies, realistic effort, costs, shared responsibilities, and slack into the plan. Completion: prerequisites have concrete resolutions and constraints reconcile across the whole plan.
3. Produce the requested usable outputs. Apply the relevant deliverable rows in the planning reference; use available document, spreadsheet, design, or other specialist skills for the actual format. A named recipe, exercise, or artifact is insufficient when instructions or a finished file are needed. Completion: required detail, quantities, calculations, sources, and artifacts are present and checked.
4. When implementation needs repeated behavior, use [routines](../steward-routines/SKILL.md); for real time placement use [scheduling](../steward-schedule/SKILL.md); for authorized practical execution use [administration](../steward-admin/SKILL.md). These are work inside the current request, not reasons to stop and ask the user to invoke another skill. Completion: reasonable setup is finished, with proposed and verified actions clearly distinguished.
5. Check for a useful adjacent opportunity using [opportunities](../steward-opportunities/SKILL.md) only when context supplies a concrete candidate. Save the plan version, relevant dependencies, artifact locations, and review point with [memory](../steward-memory/SKILL.md). Completion: connected outputs use the same assumptions; superseded outputs are marked; remaining user work is limited to real decisions or capability limits.

Use [presentation](references/presentation.md) to keep the explanation compact while retaining exact execution detail in the deliverables.
