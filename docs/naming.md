# Product naming

**Steward** is the product. The repository is `malikhense/steward`; the entry is `$steward`; all supporting skills use `steward-*` names.

The memory folder belongs to the user and can have any name. Renaming the product or its skills does not rename a vault, move personal records, or change goal identifiers.

Version 0.2.1 migrates the earlier skill namespace through the managed installer. Historical raw test evidence retains the names used during those tests; it does not define current commands. Earlier research may also mention the working title Waymark.
